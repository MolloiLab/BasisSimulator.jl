## [0.1.1] - 2026-05-17

### Added
- `CITATION.cff` — GitHub-rendered "Cite this repository" widget + tool-readable citation metadata (ORCID `0000-0002-9150-9827`).
- `.zenodo.json` — Zenodo deposition metadata (title, description, author, Julia community, declares `requires` relation to `XrayAttenuation.jl` concept DOI `10.5281/zenodo.20260565` for proper provenance).
- `CHANGELOG.md` — this file.
- `.github/workflows/release-please.yml` + `.release-please-config.json` + `.release-please-manifest.json` — release-please action auto-opens release PRs from Conventional Commits, tags + creates GitHub Release, posts `@JuliaRegistrator register` on merge.
- `.github/workflows/TagBot.yml` — standard Julia TagBot, kept alongside release-please as a fallback (no-op when release-please does the tag).
- `test/detector.jl` — 155-assertion behavioral test suite covering every exported symbol from `src/detector/` (physics_pipeline, scatter, detector_efficiency, fill_factor, optical_crosstalk, detector_lag, photon_counting, pcct/mc_response, pcct/mc_pileup).
- `test/api.jl` — regression test ensuring `build_physics_config` skips the EICT scintillator branch for PCCT scanners.

### Changed
- **`src/detector/` audit + cleanup** (1519 LOC removed, 0 live API broken):
  - `detector_lag.jl`: 722 → 166 LOC. Dropped CatSim-exact recursive IIR + alternate factories; kept `LagModel`, `lag_gadox`, `compute_lag_coefficients`, `apply_lag!`.
  - `detector_efficiency.jl`: 630 → 323 LOC. Dropped 5 unused scintillator factories (GOS/CsI/CdTe/ideal/custom), `compute_dqe`, `get_detector_efficiency_info`. Kept the GE Gemstone MC-LUT + Beer-Lambert path used live, plus CdTe and Si μ-tables needed for PCCT quantum efficiency.
  - `fill_factor.jl`: 377 → 106 LOC. Dropped 5 unused preset factories + intensity-domain twin + allocating shims.
  - `optical_crosstalk.jl`: 268 → 126 LOC. Dropped 3 unused preset factories + intensity-domain twin.
  - `scatter.jl`: dropped `default_scatter_model` (driver always uses `geometry_aware_scatter_model`) and de-exported 8 internal `SCATTER_REF_*` calibration constants.
  - `pcct/pcct_cumulative.jl`: **deleted entirely** (208 LOC). T1/T4 cumulative readouts never wired in.
- **`src/api/driver.jl::build_physics_config`**: gated the EICT detector-efficiency setup on `scanner.detector_type != :photon_counting`. PCCT scanners now route detector physics through the MC DRM in `pcct_forward_project` instead of through `PhysicsConfig.detector_efficiency`.
- **`Manifest.toml`**: `XrayAttenuation` 0.3.0 → 0.3.1 (metadata-only upstream release, picks up the upstream's first Zenodo DOI).
- **`docs/notebooks/01_five_struct_api.jl`**: simplified the 4-panel recon comparison plot — titles now read "Uncorrected" / "Corrected" and subtitles read "Standard dose" / "Low dose", with kVp/mA/correction-pipeline details moved into the figure caption.
- **`docs/notebooks/07_qrm_thorax_pure_material_vmi.jl`**: added heart-center noise ROI in the Results section anchored on the water rod with tweakable offset; cleaned up sino-denoising and BHC toggles; rebuilt 4-panel VMI mosaic and per-rod regression plots at the new full-resolution true-scan geometry.

## [0.1.0] - 2026-05-13

### Added
- Initial release, prepping for first General registry submission.
- **Five-struct API**: `Phantom`, `Scanner`, `CTProtocol`, `SimOptions`, `ReconOptions`.
- **Geometry**: cone-beam scanner model with bowtie, focal-spot, and heel-effect modeling. GE Revolution Apex Elite and Siemens NAEOTOM Alpha scanner presets.
- **Forward projection**: exact Siddon ray-voxel intersection (TIGRE-style), GPU-native via AcceleratedKernels.jl (Metal/CUDA/ROCm/CPU).
- **Polychromatic physics**: Beer-Lambert spectral sum with vendor-realistic detector response — MC-derived efficiency LUT for the GE Gemstone Ce:(Tb,Lu)₃Al₅O₁₂ scintillator (captures Tb/Lu K-edge fluorescence escape) and MC-derived response matrix + pile-up matrix for Siemens NAEOTOM Alpha CdTe.
- **Detector physics**: fill factor, scatter (Ohnesorge convolution, geometry- and phantom-size-aware), optical crosstalk, detector lag, focal-spot blur.
- **Reconstruction**: FDK (Feldkamp-Davis-Kress) and Hybrid IR with PWLS refinement.
- **Corrections**: bowtie-aware sinogram + image-domain BHC, low-signal noise floor, radial cupping, PCCT pile-up correction.
- **Spectral imaging**: dual-kVp and PCCT material decomposition (Cong 2022 per-ray Newton, Alvarez-Macovski polynomial calibration, PWLS-L₂ SQS).
- **Virtual monoenergetic imaging**: textbook VMI synthesis + Grant 2014 Mono+ frequency split with phantom-aware masking.
- **Denoising**: sinogram-domain SVD denoiser, image-domain bilateral filter.
- 7 end-to-end Pluto notebooks covering: the Five-Struct API tour, XCAT custom-material phantoms, dual-kVp VMI on Gammex 472, PCCT VMI on Gammex 472, XCAT-to-recon affine grid handling, CatSim vs BasisSim parity benchmark, and a full-resolution true-scan QRM-Thorax reference.
